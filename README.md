# Duel for the World — The Political Card Game


A satirical, turn-based card duel about power, elections and scandals, in the
spirit of Yu-Gi-Oh. Deploy politicians, play Policies, set Scandals, send your
rivals to the Embassy, and win on Election Night.

- **Editions:** the **World Edition** (English, the global base game) and
  **Edición Colombia** (a special edition with the original Spanish cards).
- **Modes:** a guided first duel (the tutorial), play against the computer
  (Easy / Normal / Hard, fully offline) or against a person online (room
  codes).
- **Feel:** synthesized sound effects and music, vibration on hits and
  scandals (all switchable in Settings), turn banners and battle animations.
- **Platforms:** a web app, wrapped as an Android app with Capacitor. It is
  built landscape-first for phones.
- All characters are fictional archetypes. No real politicians' names or faces.

## Quick start

Requirements: Node.js 22+ and pnpm.

```
pnpm install
pnpm dev
```

`pnpm dev` starts the game server (ws://localhost:8080) and the web app
(Vite prints the address, usually http://localhost:5173). Open it and choose
**Play vs Computer**. **Play Online** needs the server running; open the app in
two browser windows to play yourself.

## Commands

| Command | What it does |
|---|---|
| `pnpm dev` | Game server + web app, for playing and development (`pnpm duel` also works) |
| `pnpm test` | All unit tests (Vitest), including a full play-through of the tutorial |
| `pnpm typecheck` | TypeScript checks for every package |
| `pnpm build` | Production build of the web app (`apps/duel-web/dist`) |
| `pnpm balance` | The balance simulator (see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)) |
| `pnpm docs:cards` | Regenerates [docs/CARDS.md](docs/CARDS.md) from the card data |
| `pnpm android:run` | Builds and installs the Android app on a connected phone (see [docs/ANDROID.md](docs/ANDROID.md)) |
| `pnpm android:bundle` | Builds the signed `.aab` to upload to Google Play |
| `pnpm android:setup` | Re-applies the Android touch-ups: landscape, full screen, vibration, name, icon, signing |

## Repository layout

```
apps/
  duel-web/          The game client: menus, board, AI matches, Android shell
    src/             TypeScript UI (no framework), styles, card art (SVG)
      guide/         The tutorial: its script, the scripted opponent, the coach
      audio/         Synthesized sound, music, vibration and settings
    android/         The Android project (generated by Capacitor, then set up)
    scripts/         android-setup.mjs (landscape + full screen)
packages/
  duel-content/      Card data, editions, effect vocabulary, rules text
  duel-engine/       The rules: pure, deterministic, fully unit-tested
  duel-server/       Rooms, redaction, the online server, the AI opponent
    scripts/         balance simulator, smoke test, card-docs generator
    branding/        The app icon and launch screen images for Android
docs/                Rules, architecture, cards, Android, roadmap
store/               Google Play listing texts, icon, feature graphic, privacy policy
```
